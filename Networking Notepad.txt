
NETWORKING BASICS FOR DEVOPS 

1. Introduction to Networking
Networking is the process of connecting computers, servers, devices, and systems together to share data and resources.

Examples:
- Accessing websites
- Connecting cloud servers
- SSH remote access
- Kubernetes communication

--------------------------------------------------

2. Types of Networks

LAN (Local Area Network)
- Covers small area
- High speed
- Example: Office WiFi

WAN (Wide Area Network)
- Covers large areas
- Internet is the biggest WAN

MAN (Metropolitan Area Network)
- Covers city-level networks





What is Network Topology?

Network topology is the physical or logical arrangement of computers, switches, routers, and cables in a network.

It defines:

How devices are connected
How data flows
Network performance and reliability

1. Bus Topology
2. Star Topology 
3. Mesh Topology
4. Ring Topology
5. Hybrid Topology
--------------------------------------------------

3. OSI Model

Layer 7 - Application
Layer 6 - Presentation
Layer 5 - Session
Layer 4 - Transport
Layer 3 - Network
Layer 2 - Data Link
Layer 1 - Physical

Important:
- HTTP works in Application Layer
- TCP works in Transport Layer
- IP works in Network Layer


=========================================================

What are Network Devices?

Network devices are hardware components used to connect, manage, and communicate between computers and networks.

Purpose:
- Data communication
- Network management
- Internet connectivity
- Security

Examples
-----------

1. Hub
- Connects multiple devices
- Sends data to all devices

2. Switch
- Connects devices in LAN
- Uses MAC address
- Sends data to correct device

3. Router
- Connects different networks
- Provides internet access
- Uses IP address

4. Modem
- Connects network to ISP
- Converts signals

5. Access Point (AP)
- Provides WiFi connectivity

6. Firewall
- Secures network
- Blocks unauthorized access

7. Load Balancer
- Distributes traffic across servers

8. Repeater
- Boosts weak network signals

9. NIC (Network Interface Card)
- Connects computer to network
--------------------------------------------------

TCP vs UDP – Difference

--------------------------------------------------

1. Definition

TCP (Transmission Control Protocol)
- Connection-oriented protocol
- Reliable communication

UDP (User Datagram Protocol)
- Connectionless protocol
- Faster communication

--------------------------------------------------

2. Major Differences

Feature              		  TCP                         UDP
--------------------------------------------------------------
Connection    		Connection-oriented         Connectionless
Reliability            	Reliable                    	Unreliable
Data Delivery         	Guaranteed                  	Not guaranteed
Speed                  	Slower                      	Faster
Error Checking       	Yes                         		Basic
Packet Order          	Maintained                  	Not maintained
Acknowledgement   	Required                    	Not required
Retransmission       	Yes                         		No
Overhead              	High                        		Low

--------------------------------------------------

3. TCP Features

- Establishes connection before communication
- Uses 3-way handshake
- Ensures data delivery
- Resends lost packets
- Reliable communication

Examples:
- HTTP
- HTTPS
- SSH
- FTP
- Email
- Database connections

--------------------------------------------------

4. UDP Features

- No connection setup
- Faster communication
- No retransmission
- Suitable for real-time applications

Examples:
- Video streaming
- Online gaming
- DNS queries
- Live streaming

--------------------------------------------------

1. What is a Protocol?

A protocol is a set of rules used for communication between devices over a network.

Examples:
- HTTP
- HTTPS
- FTP
- SSH
- DNS

--------------------------------------------------

2. What is a Port Number?

A port number identifies a specific service or application running on a server.

Example:
- Website -> Port 80
- Secure Website -> Port 443

Range:
0 - 65535

SUBNETTING & CIDR 

--------------------------------------------------

1. What is Subnetting?

Subnetting is the process of dividing a large network into smaller networks called subnets.

Purpose:
- Better network management
- Improved security
- Efficient IP usage
- Reduced network traffic

--------------------------------------------------

2. Why Subnetting is Important?

Advantages:
- Improves performance
- Reduces broadcast traffic
- Better security
- Efficient IP allocation
- Easier troubleshooting

Used in:
- AWS VPC
- Kubernetes
- Enterprise Networks
- Cloud Infrastructure

--------------------------------------------------

3. What is a Subnet?

A subnet is a smaller network created from a larger network.

Example:
Network:
192.168.1.0/24

Can be divided into:
192.168.1.0/25
192.168.1.128/25

--------------------------------------------------

4. What is CIDR?

CIDR = Classless Inter-Domain Routing

CIDR notation represents:
IP Address + Network Bits

Example:
192.168.1.0/24

Meaning:
- 24 bits are network bits
- Remaining 8 bits are host bits

--------------------------------------------------

5. CIDR Format

Format:
IP_Address/Network_Bits

Example:
10.0.0.0/16

--------------------------------------------------

6. Understanding Network Bits

IPv4 Address:
32 bits total

Example:
/24

Means:
24 bits -> Network
8 bits -> Hosts

--------------------------------------------------
